# DocuSwiss

Помощь с административными документами в Швейцарии: понятная правовая информация и подготовка писем на 4 языках (FR · DE · EN · UA).

## Как запустить

Нужен установленный [Node.js](https://nodejs.org) (версия LTS).

```bash
npm install      # один раз: скачать зависимости (Vite и Sass)
npm run dev      # запустить сайт локально — откройте адрес, который покажет терминал
npm run build    # собрать готовый сайт в папку dist/ для публикации
npm run preview  # посмотреть собранную версию
```

Пока работает `npm run dev`, любые изменения в HTML, SCSS, JS и переводах сразу видны в браузере без перезагрузки.

## Структура проекта

```
docusuiss/
├── index.html              ← единственная страница (тексты на французском по умолчанию)
├── public/                 ← файлы «как есть» (иконка сайта)
├── src/
│   ├── main.js             ← точка входа: подключает стили и запускает модули
│   ├── scripts/
│   │   ├── i18n.js         ← переключение языков
│   │   ├── header.js       ← шапка: тень и мобильное меню
│   │   └── faq.js          ← аккордеон «Частые вопросы»
│   ├── locales/            ← ВСЕ ТЕКСТЫ САЙТА: fr.json, de.json, en.json, uk.json
│   └── styles/
│       ├── main.scss       ← только подключения остальных файлов
│       ├── helpers/        ← функции rem(), fluid() и миксины (медиазапросы, hover)
│       ├── base/           ← нормализация, переменные (цвета, шрифты), глобальные стили
│       ├── components/     ← повторяющиеся элементы: кнопки, заголовки секций, метки
│       └── blocks/         ← стили каждого блока страницы (шапка, hero, FAQ, подвал…)
├── vite.config.js
└── package.json
```

## Как поменять текст

1. Найдите в `index.html` нужный элемент и посмотрите его ключ, например `data-i18n="hero.subtitle"`.
2. Откройте `src/locales/uk.json` (или другой язык) и измените значение по этому ключу.
3. Новый текст? Добавьте атрибут `data-i18n="новый.ключ"` в HTML и этот ключ во **все четыре** JSON-файла.

## Правила проекта

- На сайте пишем только то, что уже реально работает.
- Каждый юридический текст проверяет юрист (Игорь) перед публикацией.
- Секреты (ключи API) храним только в файле `.env`, который не попадает в git.
